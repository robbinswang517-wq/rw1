# wheelaa 实机验证

云端没有 USB 手机或车机，以下项目需在停车后执行并记录设备型号、系统版本、网络拓扑和结果。

1. 接收设备安装 githubDebug APK，应用显示为 wheelaa，和 DiAuto 可共存。首次安装引导和权限可完成。
2. 启动网页监听，车机能加载配对页；错误码被拒绝，5 次尝试后限流，30 秒后可重试。第二个浏览器不得抢占。
3. USB 连接支持 AA 的手机，完成授权；浏览器出现与接收端一致的 AA 画面。再独立验证无线连接，勿将 USB 成功当成无线成功。
4. 点击四角和中心、地图拖动、长按、手指拖出画面后松开；核对位置和手势。横竖屏、全屏、不同屏幕比例重复测试。
5. 按住地图后断开浏览器网络，确认手机不持续拖动；15 秒后新浏览器可配对。
6. 接收端退到后台，浏览器显示等待且无法控制；回到投影后恢复。关闭服务、旋转、退出连接和重新开启不能复用旧令牌或旧帧。
7. 分别验证接收端扬声器、车载蓝牙音乐、导航播报和麦克风；浏览器本身不播放音频。
8. 验证网页 /source.zip 可下载源码，并能在另一台 Android Studio 中构建同一版本。
9. 连续运行 20 分钟，记录温度、可见卡顿、断线恢复和端到端延迟；首版目标最多 10 fps，不是 60 fps。

日志不得包含配对令牌或私密手机内容。实机未完成前，状态为“可构建实验版”，不声明车机兼容性。
